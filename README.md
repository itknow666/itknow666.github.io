# ITKNOW · 学习与工程记录

个人网站：<https://itknow666.github.io/>。这是一个静态网站，直接打开 `index.html` 或使用本地静态服务器即可浏览。

站点记录 AI 辅助学习与实践，不将公开预训练模型或未做硬件验收的结果描述为自主训练结果或实物实测成绩。比赛模型成绩来自公开验证集，隐藏测试结果未知。

项目页面通过 `.nojekyll` 保留代码和 Markdown 原文件，链接提供原始文本。部分历史记录保存的本机路径只表示实验当时的配置，不能直接作为跨机器复现命令；请先检查和调整。
