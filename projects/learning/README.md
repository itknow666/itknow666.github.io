# AI 学习路线与练习

`课程/` 与 `参考答案/` 包含从 Python、数据与张量到视频识别、实验评估和交付的 13 节配套 notebook。它们是 AI 辅助整理的学习资料；另一工作区的学习讨论已进行到第 04 课张量与自动求导，原课程勾选状态尚未更新。

为避免公开原始图片和本机输出，本版本移除了所有 notebook 输出；部分课程依赖本地比赛数据或环境，路径需自行配置。参考答案用于学习，不代表独立完成记录。

此外可查看 `../snn/lif_quickstart.py` 的 LIF 神经元练习、`../c-basics/` 的 C 语言基础练习，以及动作识别项目中的实验和环境说明。
