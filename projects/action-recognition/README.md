# 观行知意比赛：实验与代码记录

这个目录整理了项目每次尝试的源码、实验配置、训练日志、验证结果与方法对比。保留历史实验原有名称；部分绝对路径已替换为 `<项目目录>`，复现时应依据当前环境修改。

- `optimized/`：多种模型、训练与评估脚本。
- `baseline/`：基于官方开发包的工作副本。
- `runs/`：各轮实验的配置、日志、结果、对比和总结。实验分支是不同尝试，不代表单模型连续训练全部轮次。
- `competition/`：赛事材料来源、许可证、第三方实现及规则记录。
- `docs/`、`environment/`、`reports/`：赛题说明、环境与报告指导。
- `权重索引.json`：各次最佳权重的文件大小和 SHA256，用于核对；权重本身保存在本地。

## 当前结果

R(2+1)D-34 与 Video Swin-T 的融合在公开验证集取得 318/466（68.24%），Macro F1 为 63.04%，推理总参数约 9402 万。该结果并非组织方隐藏测试成绩。Linux 官方环境尚未验证；公开验证集被多次用于模型选择，存在选择偏差。

## 文件范围

为控制仓库大小，不包含原始比赛数据、图像预览、缓存、Python 环境、大模型权重、优化器断点和二进制预测数组。它们不会因为上传而从本地删除。`权重索引.json` 中记录各次 best_ema.pt 的 SHA256；由于不含这些权重，仓库本身不能直接复现训练好的模型，需从原项目获取相应文件。正式比赛提交的最终权重按赛事要求通过赛事管理 QQ 发送。

部分历史训练配置和汇总保存了运行时本机路径；当前仓库的日志、JSON 与文档中项目绝对路径已做脱敏，训练前请在当前工作环境重新配置数据与权重路径。第三方代码、许可证及预训练权重来源见 `competition/` 和各实验配置。
