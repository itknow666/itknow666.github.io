# 后续优化思路（2026-11-10）

## 依据

现有最优是 R(2+1)D-34 + Video Swin-T + 共享人物检测器：公开验证 318/466，准确率 68.24%，固定40类 Macro F1 63.04%，总参数 94,023,082。验证集已经被反复用于模型选择，分数存在选择偏差，不能等同于正式测试结果。

对其 466 个预测与标签逐项比较，主要错误方向包括：弓步蹲→深蹲6段、写字→阅读文件4段、玩游戏→使用手机4段、倒饮料→搅拌饮料4段。写字验证集仅5段、观看电视仅3段，它们在本次预测中召回均为0；少量样本造成统计波动，不能代表真实人群的准确率。第35类弓步蹲共11段，召回2/11。

继续训练 C3D 共12轮，单模型 47.42%；与X3D融合 56.22%。此前扩框1.4→1.8的六轮续训降低了准确率，此结果不能说明其他裁剪或从头微调一定无效。MViT-V2-S训练6轮达60.94%，最佳检查点在最后一轮，值得作为中等优先级继续研究，但其预训练和优化方案不同，不能直接比较架构上限。

## 建议按顺序尝试

1. **检查关键细节与裁剪**：整理上面四组错误的同步原图，标注手部、腿部或工具是否在画面和裁剪框内。优先尝试保留手部细节的高分辨率输入或基于现有图像的全身/局部双视角；不能从原图中恢复已出画的肢体。先评估视角是否补充现有模型错误，再考虑是否训练新分支；全部推理参数仍不得超过100M。
2. **研究深度与IR各自贡献**：构建训练集内部按人物划分的开发集；比较只用深度、只用IR和同步双路融合，保持同一划分和可比训练预算。避免把公开验证集纳入梯度更新。优先用 X3D-M 等小网络验证方案，再决定如何加入现有系统。相关多模态融合研究可参考 https://openaccess.thecvf.com/content_ICCV_2019/papers/Kong_MMAct_A_Large-Scale_Dataset_for_Cross_Modal_Human_Action_Understanding_ICCV_2019_paper.pdf；其中额外模态不应照搬到本题。
3. **MViT适度续训并比较互补性**：它在第6轮达到60.94%，并非已证明收敛；可以从现有检查点开展独立续训，保留现有最优。当前 MViT + R34 + 检测器略超100M，不能直接合并；应单独评估或与更小模型组合。
4. **类别不均衡的受控实验**：仅按训练集统计设计采样或损失；改变一项参数，检查每类召回、Macro F1及总体准确率。小样本类需检查标签与样本，不能根据验证标签修改训练标签。
5. **蒸馏放在有较强教师后**：比较同一学生的常规训练与仅使用允许模态、训练集进行的教师蒸馏；主要目标是压缩或延迟优化，不能预设准确率必增。

新方案先以训练集内部人物隔离的开发集作主要比较，公开验证集尽量只用于少量里程碑确认；最终仍需对466段实际原图推理、核对CSV与权重、检查100M及离线接口，并在官方Linux环境复现。禁止使用外部CUHK-X权重或额外模态。
