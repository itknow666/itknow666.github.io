# 第四轮受控实验

预先登记的方案见 `plan.json`，完整源码在项目的 `optimized/`。各组共用同一初始权重、随机种子42、6轮预算和训练增强；先比较扩框，再比较分阶段微调，最后比较两个额外学习率。此顺序方案能比较局部条件，不等于所有因素的完整网格。

1. `control16-v4-20261027`：原扩框1.4，全层微调，骨干学习率1e-5。
2. `wide16-v4-20261027`：扩框1.8，其余同对照。
3. `staged16-v4-20261027`：选择前两组表现较好的裁剪策略，前2轮冻结stem、layer1、layer2，后4轮解冻并将学习率乘0.5。
4. `lr5e6-v4-20261027`、`lr2e5-v4-20261027`：沿用选定策略，分别比较5e-6和2e-5；1e-5结果复用，不重复训练。

每个实验目录保存 `config.json`、`history.jsonl`、`best_ema.pt`、`last_ema.pt`、`resume.pt`、`summary.json` 和缓存预测。选取准确率优先、固定40类Macro F1其次；分数相同保留较简单对照。

训练损失是模型优化的目标。训练准确率只反映训练样本拟合程度，验证准确率/F1才用于比较对未见人物的泛化；最后仍需隐藏测试确认。公开验证集反复用于选择会有选择偏差，因此不能把小幅涨分直接当成真实泛化提升。

冻结检查 `stage-check.json` 验证早期层不收梯度、BN统计不变，解冻后恢复。裁剪对照图在 `cache/wide16-v4-20261027/crop-comparison.png`，红框是原策略，绿框是扩大策略；它不能证明所有画面中的手、脚和物体都已被正确保留。

运行命令（在项目根目录，已有任务运行时不要重复启动）：

```powershell
& ./.venv/Scripts/python.exe optimized/run_ablation_v4.py
# 训练完成后，从真实图片复验两个候选，检查离线加载，生成报告与独立桌面包。
& ./.venv/Scripts/python.exe optimized/finalize_ablation_v4.py
```

已有完整实验会被跳过，中断实验必须存在resume.pt才会自动恢复；没有完整epoch断点的失败任务需要先检查。保留全部旧模型，只有完整验证通过且优于旧最佳时才更新latest-model.json。本轮不租云端、不安装新依赖，不更改显卡功耗或系统设置。
