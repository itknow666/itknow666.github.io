# 网页作品说明填写稿

作品名：【团队填写】。本作品面向40类人体日常动作识别，输入为同步深度伪彩图和IR灰度图，使用四通道R(2+1)D-34。默认每段均匀取16帧并缩放至128×128。

代码包根目录包含inference.py与config.json，训练程序位于training。环境采用Python3.10及配套PyTorch/torchvision，具体版本与跨平台验证结果见技术报告。测评入口实例化Model(config, device)，predict(sample_path)返回固定类别顺序的40个分数。

权重单独提供为model.pt，与config.json中的weights_file一致；入口将其解析为weights_path。推理不下载模型、不调用在线API，也不需要训练缓存或标签。

复现步骤：准备已登记依赖 → 将model.pt置于代码目录 → 运行python predict.py --dataset /path/to/validation --config config.json --output validation.csv。最终完整验证结果、权重SHA256、Linux验证情况和技术亮点：【完成完整实验后填写】。
