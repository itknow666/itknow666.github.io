# STM32 信号测量工程：代码与验证摘录

基于 STM32F103C8T6、HAL 和 Keil 的周期信号测量工程，包含采集、测量、显示、按键和校准逻辑。此目录保留核心源码与实际验证记录，不包含完整的厂商 HAL、字体、Keil 工程文件或板级资料，不能作为完整工程直接编译。

`evidence/validation.json` 和构建日志记录了 Keil Arm Compiler 6.24 编译 0 错误、0 警告，以及 3,997 项合成信号算法检查、93 项模拟外设应用检查。**实物板未连接、未烧录，也未进行硬件精度验收**；软件测试不能证明实际测量精度。

源码由学习者与 AI 辅助协作完成；原工程中的 STMicroelectronics HAL/CMSIS 由其各自许可证约束，未在本摘录中重新发布。
