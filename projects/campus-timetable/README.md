# Android 课表与桌面小组件

一个离线 Android 课表练习，使用原生 Java Activity、WebView、AppWidgetProvider 和 RemoteViews，支持教学周计算、课程编辑和桌面小组件。应用构建与 AI 辅助协作完成。

原项目的 1.2 版本记录显示：APK 资源与签名校验通过，原生与 JavaScript 排课结果对照覆盖 217 天；真机和模拟器桌面尚未测试。2026-11-12 重新运行原项目排课测试，通过教学周切换、时间边界和 30 周冲突检查。

此处提供原生 Java 部分代码和脱敏验证摘要；完整应用还需要 Web 资源、构建配置及 Android SDK。原项目中的个人课表、角色图片和签名密钥未包含在公开版本内。
